# Few-Shot Gaussian Splatting with Diffusion-Based Data Augmentation

This repository contains the core code used for the project **Few-Shot Gaussian Splatting with Diffusion-Based Data Augmentation**.

## Project Overview

The goal of this project is to study Gaussian Splatting (GS) in a few-shot setting and evaluate whether synthetic views generated by online diffusion-based models can improve or degrade reconstruction quality.

The few-shot setting uses **20 real training images** as the baseline. Synthetic views are added at four synthetic-to-real ratios:

* 25%
* 50%
* 100%
* 200%

The online generative models used for synthetic augmentation are:

* PixVerse
* Kling
* Pika
* Runway

The final evaluation is performed only on real held-out test images using:

* PSNR
* SSIM
* LPIPS

## Scripts

### `build_real_map.py`

Builds the real reference scene from the real image sequence using HLoc and COLMAP.

#### Main Role

* Extract global and local features from real images
* Retrieve and match image pairs
* Reconstruct the real sparse SfM model
* Export camera poses and sparse model files

#### Output

* Real SfM model
* Real camera poses
* COLMAP sparse model for reuse in later stages

### `inject_synthetic.py`

Localizes synthetic images with respect to the real reference map and creates mixed real and synthetic datasets.

#### Main Role

* Use the full real map as the reference scene
* Use synthetic frames generated by online models
* Localize synthetic frames into the real map
* Build GS-ready datasets
* Preserve a real-only test split
* Prevent synthetic leakage into the test set

#### Output

* Mixed GS-ready datasets for each model and synthetic ratio
* Metadata describing injected and excluded synthetic frames

### `run_gs_experiments.py`

Builds the few-shot subsets, trains Gaussian Splatting, renders held-out views, and computes evaluation metrics.

#### Main Role

* Create the 20-image real baseline
* Add the required number of synthetic images for each ratio
* Train GS for each condition
* Render test views
* Compute PSNR, SSIM, and LPIPS
* Save the final summary results

#### Output

* Trained GS runs
* Rendered test images
* Quantitative summary files

## Pipeline

The pipeline is organized into three stages:

1. **Real Map Construction**
   Build the real reference reconstruction from the real frames.

2. **Synthetic Injection**
   Localize synthetic images into the real map and create mixed datasets.

3. **Few-Shot GS Experiments**
   Build few-shot subsets, train GS, render test views, and evaluate the results.

## Notes

* The repository contains the core scripts and final results summary.
* Large datasets, generated videos, trained models, and full render outputs are not included because of file-size limitations.
* The online diffusion-based models were used as black-box augmentation tools through their web platforms.

## Results Summary

In the tested setup, the real-only few-shot baseline achieved the best overall performance.

Synthetic augmentation generally degraded Gaussian Splatting performance as the synthetic ratio increased.

Among the synthetic conditions, the best result was obtained with **PixVerse at a 25% synthetic ratio**, but it still did not outperform the real-only baseline.

## Reproducibility

To reproduce the pipeline, run the scripts in the following order:

```bash
python build_real_map.py
python inject_synthetic.py
python run_gs_experiments.py
```

The exact environment depends on:

* HLoc
* COLMAP or PyCOLMAP
* Gaussian Splatting
* The Python packages required by the scripts
